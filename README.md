# 🍔 Next.js Foodie App

A modern full-stack web application for discovering and sharing meal recipes, built with Next.js App Router and Server Actions.

## 🚀 Features
* Dynamic recipe browsing with optimized image rendering (`next/image`)
* Community meal submissions powered by Next.js Server Actions
* SQLite integration for managing recipes and local persistent state
* Page transitions and loading skeletons using Next.js layout patterns

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Language:** JavaScript / React
* **Database:** SQLite / better-sqlite3
* **Styling:** CSS Modules
